# SynergyFake

> 圧倒的「仕事してる感」演出プラットフォーム —— オフィスで絶対に話しかけられたくない現代人のための生存戦略。

---

## 概要

現代のオフィス環境は、定時直前の無意味な雑務や話の長い上司の世間話など、数々の理不尽なエンカウントに満ち溢れています。
**SynergyFake** は、ブラウザ上に「極めて高度かつ切迫した業務を行っている風」のUIと環境音を爆速で生成し、あなたの周囲に「あいつは今ヤバい、絶対に話しかけるな」という不可侵の結界を展開するWebアプリケーションです。

---

## 主要機能

- ⌨️ **爆速タイピング音 & 環境音エミュレーター（ASMR）**  
  スペースキーひとつで破滅的な青軸メカニカル乱打音を響かせ、3分ごとに絶妙な「チッ…」という低音のため息を再生します。

- 🖥️ **劇的・偽装作業画面（The Matrix Mode）**  
  緑の文字列が猛スピードで降り注ぐ「ハリウッド・ハッカー画面」や、全セルが `#VALUE!` で埋まった「地獄のExcel画面」を瞬時に全画面表示。

- 🚨 **Boss Alert（緊急迎撃モード）**  
  背後の接近を検知した瞬間、0.05秒で画面を難解な経済記事や企業理念PDFへ切り替え、マウスカーソルを細かく震わせて切迫感を偽装します。

- 🗣️ **意識高い系・独り言プロンプター**  
  「シナジーがコンフリクトを起こしてるな…」といった業界用語をモニター隅にカンペ表示。読み上げるだけで世界を動かしている空気を醸成します。
